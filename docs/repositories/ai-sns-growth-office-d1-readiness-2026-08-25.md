2. Bind it to the app as `DB`.
3. Set `AI_SNS_REPOSITORY_DRIVER=d1`.
4. Apply `migrations/0001_ai_sns_growth_office_json_tables.sql`.
5. Apply SQL generated by `npm run d1:seed:sql` when starting from an empty database.
6. Verify dashboard data persists after approval actions and reload.
